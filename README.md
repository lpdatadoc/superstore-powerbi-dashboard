# Superstore Sales Dashboard — Power BI

Interactive sales dashboard built as part of my Data Analyst portfolio.

## Dataset
Superstore Sales (Kaggle) — 9,800 rows, 2015–2018

## Dashboard pages
- **Overview**: KPIs, monthly trend, sales by category and region
- **Product Analysis**: Top 10 products, unprofitable products, sub-category performance  
- **Customer Insights**: Top customers, segment breakdown, order behaviour

## Tools
Power BI Desktop · DAX · Power Query
